# CMS da LojaBL

`sections.json` é o catálogo local de seções que o app sabe renderizar. Ele serve como contrato/documentação para o conteúdo da home: banner, prateleiras, categorias e texto.

O app continua lendo o conteúdo publicado do projeto `appdev` no VTEX Headless CMS. Portanto, editar este arquivo local não publica nem altera o CMS. Quando formos separar o projeto CMS, este contrato poderá ser usado para configurar as seções independentes da LojaBL.
