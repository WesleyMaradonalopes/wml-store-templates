# wml-store-templates

Aplicativo LojaBL para iOS e Android com React Native e Expo, integrado à VTEX.

## Estrutura

- `wml-store`: aplicativo Expo/React Native.
- `wml-backend`: backend local para integrações seguras com VTEX.

As credenciais e arquivos `.env` ficam fora do repositório. Use os arquivos `.env.example` como referência.
